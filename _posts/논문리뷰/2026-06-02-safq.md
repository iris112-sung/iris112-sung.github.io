## Introduction
이 논문은 언어모델의 내부 계산 과정을 인간이 이해할 수 있도록 회로수준(circuit)으로 분석하기 위해, 대부분의 가중치를 0으로 제한한 Weight-sparse Transformer를 학습시키는  방법을 제안한다. 일반적인 dense 모델은 모든 뉴런이 촘촘히 연결되어있기 때문에 인간이 해석하기 어렵지만, 가중치의 희소성을 강하게 부여해 각 뉴런이 소수의 연결만을 사용해 더 작고 명확한 회로가 형성된다. 실제로 파이썬 코드 기반의 단순 과제들에서 모델을 프루닝하여 필요한 최소 회로를 추출했고, 그 회로가 문자열 닫기, 괄호 깊이 계산, 변수 타입 추적 같은 인간이 이해 가능한 알고리즘으로 설명되었다.
## Introduction, **Related Work**
기계적 해석가능성의 핵심 목표는 신경망이 내부적으로 어떤 알고리즘을 구현하는지 역공학하는 것이다. 기존 Transfomer는 활성값과 가중치를 사람이 직접적으로 이해하기 어렵고, 또한 하나의 뉴런이 여러 의미를 가지는 superposition 문제가 발생한다. 기존 SAE기반 접근은 해석 가능한 특징 공간을 학습한 뒤 회로를 분석하지만, 이 방식은 모델의 실제 메커니즘보단 분석자가 선택한 추상화에 영향을 받을 수 있다. 그렇기에 저자들은 처음부터 가중치가 매우 희소한 모델을 학습시켜, 낮은 가중치의 뉴런 및 채널 단위에서도 이해 가능한 회로를 얻고자 한다.
## **Methods: Sparse Training, Measuring interpretability**
모델은 gpt-2 스타일의 decoder-only Transformer를 사용하되, 대부분의 가중치와 bias, embedding을 0으로 제한한다. 학습중에는 AdamW로 최적화한 뒤 각 weight matrix에서 절댓값이 큰 일부 항목만 남기고 나머지를 0으로 만든다. 또한 activation sparsity도 약하게 적용하여, 활성 위치에서도 일부 값만 남긴다. 모델은 파이썬 코드 데이터셋으로 사전 학습되며, 이후 사람이 설게한 20개의 단순한 Python next-token binary prediction 과제에서 평가된다.

해석가능성 측정은 각 과제에서 목표 손실을 유지하면서 필요한 최소 회로를 찾는 방식이다. 회로의 노드는 뉴런, attention channel, residual read/write channel처럼 세밀한 단위로 정의되며, edge는 weight matrix의 nonzero entry로 정의된다. 프루닝 과정에서는 불필요한 노드를 평균 활성값으로 대체하고, 과제 손실과 회로 크기를 함께 최소화하는 mask 학습 방식으로 작은 회로를 찾는다.
## **Results: Weight sparsity improves interpretability**
첫번째 핵심 결과는 weight-sparse모델이 dense 모델보다 훨씬 더 작은 과제별 회로를 만든다는것이다. 이는 비슷한 pretraining loss를 가진 sparse 모델과 dense 모델을 비교했을 때, sparse 모델의 회로가 동일한 손실 수준에서 대략 16배 더 작은 수준이다. 이는 단순 행동이 sparse 모델 안에서 더 분리되고 국소화되어 있음을 보여준다. 또한 회로에 포함된 노드만 제거하면 성능이 크게 악화되고, 회로 외의 노드를 제거해도 과제 성능이 유지되어, 추출한 회로가 과제 수행에 충분할 뿐 아니라 필요하다는 점도 검증한다. 
두 번째 결과는 모델 크기와 희소성 사이의 trade-off이다. 가중치를 더 희소하게 만들면 해석가능성은 좋아지지만 성능은 떨어진다. 반대로 전체 모델 크기를 키우면서 nonzero parameter 수를 고정하면 성능과 해석가능성의 Pareto frontier가 개선된다. 즉, 큰 sparse 모델은 같은 L0 조건에서도 더 적은 연결을 각 뉴런에 분산시킬 수 있어 더 좋은 회로 구조를 학습할 가능성이 있다.
## **Qualitative circuit investigations**
논문은 세 가지 대표 과제를 통해 실제 회로가 어떻게 해석되는지 보여준다.
첫번째로는 문자열 닫기 과제에서는 모델이 여는 따옴표가 작은따옴표인지 큰따옴표인지 감지한 뒤, attention head가 해당 정보를 복사하여 올바른 닫는 따옴표를 예측한다. 이 회로는 12개 노드와 9개 edge로 설명된다.
두번째는 리스트 중첩 깊이 계산 과제에서는 `[` 토큰을 감지하는 채널이 먼저 활성화되고, attention head가 문맥 내 open bracket 정보를 평균내어 리스트 깊이를 나타낸다. 이후 다른 attention head가 이 값을 threshold처럼 사용해 중첩 리스트인지 판단하고 `]` 또는 `]]`를 예측한다. 여기서 흥미로운 점은 저자들은 이 회로 이해를 바탕으로 긴 리스트나 방해 bracket을 넣어 모델을 실패하게 만드는 adversarial example도 구성했다. 이는 희소회로가 정확히 작동하는지 검증하기 위해 구성된것으로 보인다.
세번째는 변수 타입 추적 과제에서는 모델이 `current = set()` 또는 `current = ""` 같은 초기화 정보를 attention을 통해 복사하고, 나중에 같은 변수명이 등장했을 때 해당 타입 정보를 다시 불러와 `.add` 또는 `+=`를 예측한다. 이 회로는 완전히 단순하지는 않지만, 두 개의 attention head가 단계적으로 정보를 전달하는 구조로 부분적으로 해석 가능하다.
## **Bridges / Using bridges to extract circuits from existing models**
논문은 weight-sparse 모델을 처음부터 새로 학습시키는 방식뿐 아니라, 이미 학습된 dense 모델을 설명하는 방향도 시도한다. 이를 위해 dense 모델과 sparse 모델 사이에 bridge를 두어 각 layer의 activation을 서로 변환하게 만든다. 이후 sparse 모델에서 해석 가능한 노드를 조작하고, 그 perturbation을 bridge를 통해 dense 모델에 전달한다. 실험에서는 따옴표 타입 표현이나 `while True`와 같은 구문 표현을 조작했을 때 dense 모델의 출력 확률이 기대한 방향으로 바뀌었다. 이는 sparse 모델 회로가 dense 모델의 내부 표현과 어느 정도 대응될 수 있음을 보여주는 예비 결과다.
## **Limitations and Future Work**
가장 큰 한계는 계산 비효율성이다. 기본적으로 sparse 모델이 비슷한 능력의 dense 모델보다 학습과 추론에서 100\~1000배 더 많은 연산자원을 요구한다. 따라서 이 방법으로 frontier급 모델을 직접 학습하거나 완전히 해석하는 것은 현실적으로 어렵다. 또한 복잡한 과제에서는 여전히 polysemantic feature가 남아 있고, 일부 feature는 단순히 켜짐/꺼짐이 아니라 activation magnitude에 정보를 담기 때문에 완전한 설명이 어렵다.
또한 논문에서 사용하는 “작은 과제별 회로”라는 해석가능성 지표는 직관적인 인간 이해가능성을 완전히 담지 못한다. mean ablation도 회로의 faithfulness를 완벽히 보장하지 않기 때문에, 향후 causal scrubbing 같은 더 엄밀한 검증이 필요하다고 본다. 프루닝 역시 node단위 중심이어서 edge단위 프루닝보다 거칠며, 실제 분석에서는 추가적인 수작업 정리가 필요했다.
## **Discussion / Related Work**
이 논문은 Transformer 내부 회로를 사람이 이해할 수 있는 단위로 보여주려 했다는 점에서 의미가 있다. 특히 문자열 닫기 회로처럼 구체적인 계산 과정을 노드와 연결로 설명한 부분은, 모델이 단순히 결과를 내는 것이 아니라 내부적으로 어떤 절차를 거치는지 공부하는 데 도움이 되었다.
인상적이었던 점은, 해석가능성이 단순히 모델의 출력을 설명하는 수준을 넘어 모델의 약점까지 예측할 수 있다는 것이다. 다만 weight-sparse 모델을 새로 학습해야 한다는 한계가 있어, 현재의 대규모 언어모델에 바로 적용하기는 어렵다. 그럼에도 희소성을 이용해 더 이해하기 쉬운 모델을 만들고, 이를 dense 모델 분석으로 확장하려는 시도는 앞으로의 AI 해석가능성 연구에서 중요한 방향이라고 생각한다.
